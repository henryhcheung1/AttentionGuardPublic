# Attention Guard — Public Pages

Public-facing pages for the **Attention Guard** browser extension, a Chrome extension that enforces a minimum watch time on YouTube videos before another video can be opened. Built to help parents limit screen-switching for young children.

## Privacy policy

The extension's privacy policy is at [`PRIVACY.md`](./PRIVACY.md). The TL;DR: the extension stores two configuration values locally (a number and a boolean) and transmits nothing.
